# Project and Program Manager

> **Positioning:** A formal delivery leadership path focused on coordinating work, resources, stakeholders, risks, governance, and outcomes. Project management and program management are related but not identical.

## What This Path Is

A **Project Manager** leads a temporary initiative with defined objectives, scope, schedule, resources, risks, and stakeholders. A **Program Manager** coordinates related projects and activities to realize benefits that are not available when each project is managed separately.

A software engineering background is valuable because it helps the manager understand technical uncertainty, architecture dependencies, quality risks, delivery constraints, and the difference between a completed output and a useful outcome.

## Primary Outcomes

- Work organized around an agreed objective and value
- Realistic scope, schedule, resource, and financial expectations
- Risks, issues, assumptions, and changes visible to decision makers
- Stakeholders engaged at the right level and time
- Governance that supports decisions rather than creating ceremony
- Project deliverables or program benefits realized and reviewed

## Project Manager versus Program Manager

| Dimension | Project Manager | Program Manager |
|---|---|---|
| Primary scope | One project | Related projects and activities |
| Main concern | Deliver the project objective | Realize coordinated benefits and strategic outcomes |
| Time horizon | Project life cycle | Longer and broader change horizon |
| Coordination | Project team and stakeholders | Multiple project teams, sponsors, and governance groups |
| Success evidence | Deliverable and project outcome | Benefits, capability, adoption, and strategic contribution |


## Signals for Moving Forward

- You prefer coordinating outcomes across many contributors to focusing on one implementation area.
- You can make plans without pretending that uncertainty does not exist.
- You are comfortable with governance, budgets, contracts, and executive communication.
- You can protect the project from uncontrolled change while remaining responsive to valuable change.
- You can distinguish activity, output, outcome, and benefit.

## Evidence to Build

- Project charter
- Project management plan
- Scope statement and WBS
- Integrated schedule
- Risk and issue registers
- Stakeholder engagement plan
- Cost and forecast report
- Change log
- Project closure report
- Program benefits-management plan
