# Roadmap Planning

> A roadmap translates priorities into a time-sequenced plan. It shows what you'll build, when you'll build it, and why that sequence makes sense.

## Why Roadmap Planning Matters

**Without roadmap:**
- Priorities don't translate to execution
- Teams don't know what's next
- Stakeholders can't plan
- No visible progress toward goals

**With roadmap:**
- Priorities sequenced logically
- Teams can plan ahead
- Stakeholders can coordinate
- Progress visible and trackable

## Roadmap Types

### 1. Strategy Roadmap

**Audience:** Executives, board
**Timeframe:** 1-3 years
**Focus:** Strategic initiatives, market moves
**Detail:** High-level themes

**Example:**
```
2026: Mid-market platform launch
2027: European expansion
2028: AI-powered insights
```

### 2. Product Roadmap

**Audience:** Product teams, stakeholders
**Timeframe:** 6-12 months
**Focus:** Features, initiatives, outcomes
**Detail:** Epics and major features

**Example:**
```
Q1: Unified customer view
Q2: Real-time search
Q3: Mobile app
Q4: AI recommendations
```

### 3. Release Roadmap

**Audience:** Engineering, operations
**Timeframe:** 1-3 months
**Focus:** Releases, features, dependencies
**Detail:** User stories and tasks

**Example:**
```
Release 2.1 (March): Customer profile, order history
Release 2.2 (April): Search, filters
Release 2.3 (May): Notifications, export
```

## Roadmap Components

### 1. Time Horizons

**Now (current quarter):**
- Committed work
- High confidence
- Detailed planning
- In execution

**Next (next quarter):**
- Planned work
- Medium confidence
- Scoped but not detailed
- Ready to start

**Later (future quarters):**
- Potential work
- Low confidence
- High-level themes
- Subject to change

### 2. Themes and Initiatives

**Themes:**
- Strategic focus areas
- Group related work
- Connect to goals
- Example: "Customer efficiency"

**Initiatives:**
- Major pieces of work
- Deliver theme outcomes
- Multi-quarter scope
- Example: "Unified customer platform"

**Features:**
- Specific capabilities
- Deliver initiative value
- Quarter scope
- Example: "Customer profile page"

### 3. Milestones

**Key dates and achievements:**
- Product launches
- Major releases
- Strategic goals achieved
- External commitments

**Example:**
```
March: Platform beta launch
June: 100 customers migrated
September: General availability
December: 500 customers using platform
```

## Roadmap Planning Process

### 1. Start with Strategy

**Connect roadmap to strategy:**
- Strategic goals
- Strategic choices
- Target outcomes
- Success metrics

**Example:**
```
Strategic goal: Reduce call handling time by 30%
Roadmap theme: Customer efficiency
Initiative: Unified customer view
Features: Profile page, order history, search
```

### 2. Sequence by Dependencies

**Identify dependencies:**
- Technical dependencies (A requires B)
- Business dependencies (launch requires beta)
- Resource dependencies (team availability)
- External dependencies (partner integrations)

**Sequence logically:**
```
Must do first:
- Customer data model
- API integrations

Then:
- Unified customer view
- Real-time search

Finally:
- AI recommendations
- Advanced analytics
```

### 3. Balance Priorities

**Balance across dimensions:**
- New features vs. technical debt
- Short-term vs. long-term
- Different strategic goals
- Different user segments

**Example allocation:**
```
Q1 Roadmap:
- 60% new features (unified view, search)
- 20% technical debt (performance, scalability)
- 20% bug fixes and improvements
```

### 4. Plan for Uncertainty

**Acknowledge uncertainty:**
- Near-term: High confidence, detailed
- Mid-term: Medium confidence, scoped
- Long-term: Low confidence, thematic

**Use ranges:**
```
Unified customer view: March-April (not "March 15")
Mobile app: Q3 (not "August")
AI features: H2 2026 (not "October")
```

## Roadmap Communication

### 1. Visual Roadmap

**Make it visual:**
- Timeline view
- Swim lanes by theme
- Color coding by status
- Milestones marked

**Tools:**
- Productboard
- Aha!
- Roadmunk
- Simple Gantt charts

### 2. Narrative Roadmap

**Tell the story:**
```
"In Q1, we're building the foundation with unified customer
view. This directly supports our strategic goal to reduce call
handling time. In Q2, we'll enhance with real-time search,
making the platform even more efficient. By Q3, we'll expand
to mobile, serving reps in the field."
```

### 3. Audience Adaptation

**Executives:**
- Strategic alignment
- Market positioning
- Business outcomes

**Teams:**
- What we're building
- When we're building it
- Why this sequence

**Customers:**
- What's coming
- When to expect it
- How it helps them

## Roadmap Management

### 1. Regular Reviews

**Review cadence:**
- Weekly: Execution progress
- Monthly: Roadmap adjustments
- Quarterly: Strategic alignment

**Review questions:**
- Are we making progress?
- Do priorities need adjustment?
- Are assumptions still valid?
- What did we learn?

### 2. Adaptation

**When to adapt roadmap:**
- Strategic direction changes
- Market conditions shift
- Major learnings from customers
- Resource constraints emerge

**How to adapt:**
- Communicate changes clearly
- Explain rationale
- Update stakeholders
- Adjust plans

### 3. Tracking Progress

**Track:**
- Initiative progress
- Milestone achievement
- Goal progress
- Roadmap accuracy

**Metrics:**
- % of roadmap delivered on time
- Milestone achievement rate
- Strategic goal progress
- Roadmap stability (changes per quarter)

## Common Roadmap Mistakes

### 1. Overcommitment

**Mistake:** Promising too much
**Fix:** Under-promise, over-deliver. Use ranges.

### 2. False Precision

**Mistake:** Specific dates for uncertain work
**Fix:** Use quarters, halves, ranges

### 3. Feature List

**Mistake:** Roadmap is just features
**Fix:** Connect to outcomes and strategy

### 4. Set and Forget

**Mistake:** Create roadmap, never update
**Fix:** Regular reviews and adaptation

### 5. Ignoring Dependencies

**Mistake:** Sequencing without dependencies
**Fix:** Map dependencies, sequence logically

## Senior-Level Roadmap Planning

1. **Strategic roadmapping**
   - Not just product features
   - Strategic initiatives
   - Market moves
   - Organizational changes

2. **Manage uncertainty**
   - Communicate uncertainty clearly
   - Plan for multiple scenarios
   - Adapt as you learn

3. **Align organization**
   - Connect roadmaps across teams
   - Coordinate dependencies
   - Build shared understanding

4. **Drive execution**
   - Translate roadmap to execution
   - Track progress
   - Ensure delivery

## Metrics

- Roadmap delivery rate (% delivered on time)
- Milestone achievement rate
- Roadmap stability (changes per quarter)
- Strategic goal progress
- Stakeholder satisfaction with roadmap
