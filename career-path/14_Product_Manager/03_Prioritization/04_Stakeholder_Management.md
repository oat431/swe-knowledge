# Stakeholder Management

> Prioritization happens in a political context. Different stakeholders have different priorities, and managing these relationships is as important as the prioritization framework itself.

## Why Stakeholder Management Matters

**Without stakeholder management:**
- Priorities overridden by politics
- HiPPO (Highest Paid Person's Opinion) dominates
- Team frustration with changing priorities
- Misalignment between strategy and execution

**With stakeholder management:**
- Aligned priorities across organization
- Transparent decision-making
- Managed expectations
- Sustainable prioritization

## Stakeholder Mapping

### Identify Stakeholders

**Who cares about priorities?**
- Executive leadership (CEO, CPO, CTO)
- Product managers
- Engineering leadership
- Sales and marketing
- Customer success
- Customers (indirectly)

### Stakeholder Analysis

For each stakeholder, assess:
- **Interest:** How much do they care?
- **Influence:** How much can they affect decisions?
- **Perspective:** What's their priority lens?

**Stakeholder matrix:**
```
High Influence + High Interest = Manage closely
High Influence + Low Interest = Keep satisfied
Low Influence + High Interest = Keep informed
Low Influence + Low Interest = Monitor
```

### Common Stakeholder Perspectives

**Sales:**
- Focus: Revenue, customer requests
- Priority: Features that close deals
- Timeframe: This quarter

**Engineering:**
- Focus: Technical quality, scalability
- Priority: Architecture, technical debt
- Timeframe: Long-term sustainability

**Customer Success:**
- Focus: Customer satisfaction, retention
- Priority: Bug fixes, usability improvements
- Timeframe: Immediate customer needs

**Executive:**
- Focus: Strategic goals, market position
- Priority: Strategic initiatives
- Timeframe: Annual and beyond

## Stakeholder Engagement

### 1. Early Involvement

**Before prioritizing:**
- Understand stakeholder priorities
- Share prioritization framework
- Set expectations about process
- Get input on criteria

**Benefits:**
- Stakeholders feel heard
- Better input for decisions
- Easier to defend decisions later

### 2. Transparent Process

**Make prioritization visible:**
- Share framework and criteria
- Show how decisions made
- Document rationale
- Communicate trade-offs

**Example:**
```
"We used RICE scoring to prioritize Q3 initiatives.
Here's how each opportunity scored and why we chose
the top 3. We deferred X because it scored lower on
strategic alignment, despite high user value."
```

### 3. Regular Communication

**Keep stakeholders informed:**
- Prioritization decisions
- Rationale for decisions
- Changes to priorities
- Progress against priorities

**Cadence:**
- Executive: Monthly reviews
- Leadership: Bi-weekly updates
- Teams: Weekly standups

## Managing Competing Priorities

### 1. Objective Criteria

**Use frameworks, not opinions:**
- RICE, MoSCoW, Value/Effort
- Consistent application
- Documented rationale
- Evidence-based decisions

**When stakeholder disagrees:**
- "I understand you want X prioritized. Our framework
  scored it at Y because of Z. What additional evidence
  should we consider?"

### 2. Trade-off Conversations

**Make trade-offs explicit:**
- "If we prioritize A, we must defer B"
- "This requires X resources, which means Y gets less"
- "Choosing this path means not pursuing that path"

**Example:**
```
Stakeholder: "We need to build the mobile app now!"

Response: "Building mobile app (6 months) means deferring
unified customer view (3 months). Unified view has higher
RICE score (200 vs 17) and directly supports our strategic
goal to reduce call time. Should we revisit our strategic
priorities, or proceed with unified view first?"
```

### 3. Escalation Paths

**When stakeholders can't agree:**

**Level 1:** Product manager decision
- Use framework
- Document rationale
- Communicate decision

**Level 2:** Leadership alignment
- Bring to product leadership
- Present trade-offs
- Seek alignment

**Level 3:** Executive decision
- Strategic disagreements
- Resource allocation conflicts
- Final arbitration

### 4. Managing HiPPO

**Highest Paid Person's Opinion:**

**Don't:**
- Blindly accept executive requests
- Argue without evidence
- Ignore executive input

**Do:**
- Understand the underlying need
- Provide evidence-based response
- Show trade-offs clearly
- Align with strategic goals

**Example:**
```
Executive: "We need to build feature X immediately!"

Response: "I understand this is important. Can you help
me understand the business need? [Listen]

Based on our research, feature X would help 200 users
save 1 hour per week. Feature Y would help 1000 users
save 5 hours per week. Both are valuable, but Y has
5x the impact. Should we:
1. Build Y first, then X
2. Revisit our strategic priorities
3. Find resources to do both"
```

## Building Stakeholder Alignment

### 1. Shared Understanding

**Ensure everyone understands:**
- Strategic goals
- Prioritization framework
- Current priorities
- Trade-offs made

**Methods:**
- Strategy sessions
- Prioritization workshops
- Documentation
- Regular updates

### 2. Collaborative Prioritization

**Involve stakeholders in process:**
- Prioritization workshops
- Scoring sessions
- Trade-off discussions
- Decision reviews

**Benefits:**
- Better decisions (more input)
- Greater buy-in (participation)
- Shared ownership (collaboration)

### 3. Success Metrics

**Align on what success looks like:**
- Strategic goal metrics
- Initiative success criteria
- Progress tracking
- Outcome measurement

**Example:**
```
Initiative: Unified customer view
Success metrics:
- Call handling time reduced by 30%
- Customer satisfaction increased to 4.5
- Representative satisfaction increased to 4.0

Stakeholders agree these metrics define success.
```

## Common Stakeholder Management Mistakes

### 1. Ignoring Stakeholders

**Mistake:** Prioritize in isolation
**Fix:** Engage stakeholders early and often

### 2. Over-Accommodating

**Mistake:** Say yes to every request
**Fix:** Use frameworks, make trade-offs explicit

### 3. Poor Communication

**Mistake:** Decisions made without explanation
**Fix:** Communicate rationale, show trade-offs

### 4. Inconsistent Application

**Mistake:** Apply framework differently for different stakeholders
**Fix:** Consistent application, document exceptions

### 5. Not Managing Expectations

**Mistake:** Stakeholders expect everything
**Fix:** Set clear expectations about capacity and trade-offs

## Senior-Level Stakeholder Management

1. **Influence strategically**
   - Not just manage stakeholders
   - Shape stakeholder perspectives
   - Build strategic alignment

2. **Navigate politics**
   - Understand organizational dynamics
   - Build coalitions
   - Manage power relationships

3. **Build prioritization culture**
   - Evidence-based decisions
   - Transparent processes
   - Shared ownership

4. **Manage executive relationships**
   - Build trust with leadership
   - Provide strategic counsel
   - Balance advocacy and reality

## Metrics

- Stakeholder satisfaction with prioritization (survey)
- Priority stability (how often priorities change)
- Decision speed (time to align)
- Escalation rate (how often decisions escalated)
- Alignment score (stakeholder agreement)
