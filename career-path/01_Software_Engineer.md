# Software Engineer

> **Positioning:** The starting role in this career map. A software engineer applies engineering principles to understand, build, test, operate, and improve software systems.

## What This Path Is

A software engineer turns problems and requirements into working software. The role includes more than writing code: it involves understanding users, choosing designs, verifying behavior, collaborating with other disciplines, and supporting the system after release.

The role is a foundation for both technical and non-technical paths. The engineer develops enough breadth to understand the software lifecycle, then chooses where to increase scope or specialization.

## Primary Outcomes

- Working software that solves a real problem
- Understandable and maintainable code
- Appropriate tests and quality controls
- Safe and repeatable delivery
- Useful technical documentation
- Clear communication with teammates and stakeholders
- Responsible operation and maintenance of the system

## Signals for Moving Forward

- You can deliver features with decreasing supervision.
- You can explain the trade-offs behind your implementation.
- You can identify and communicate risks early.
- You can help teammates understand the system.
- You can participate in requirements, design, testing, and operations discussions.
- You are curious about either broader scope or a deeper specialization.

## Evidence to Build

- A feature delivered from requirement to production
- A design note or architecture decision record
- A test strategy for a meaningful change
- A production runbook or operational improvement
- A code review that explains a design trade-off
- A retrospective showing what changed in your engineering practice
